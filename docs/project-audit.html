7 Triage: AFK vs HITL

AFK ready-for-agent

Apply when ALL conditions are met:

  • Acceptance criteria are concrete and testable
  • No external account setup, secrets, or OAuth flows
  • No UX judgment calls — what-to-build is fully specified
  • No dependency on unmerged work
  • Existing patterns in codebase to follow

HITL ready-for-human

Apply when ANY condition is true:

  • Needs design decisions (layout, UX flow, visual direction)
  • Requires external service setup (OAuth, API keys)
  • Involves security-sensitive code (auth, tokens)
  • Acceptance criteria are ambiguous
  • First-of-its-kind pattern, no reference code
  • Issue is an epic or PRD
