5 Triage: AFK vs HITL

AFK ready-for-agent

Apply when ALL conditions are met:

  • Acceptance criteria are concrete and testable
  • No external account setup, secrets, or OAuth flows
  • No UX judgment calls — what-to-build is fully specified
  • No dependency on unmerged work
  • Existing patterns in codebase to follow

HITL ready-for-human

Apply when ANY condition is true:

  • Needs design decisions (layout, UX flow, visual direction)
  • Requires external service setup (OAuth, API keys)
  • Involves security-sensitive code (auth, tokens)
  • Acceptance criteria are ambiguous
  • First-of-its-kind pattern, no reference code
  • Issue is an epic or PRD

6 Sandcastle (AFK Agent Pipeline)

How it works
Sandcastle runs Claude Code agents in Docker sandboxes. A Planner reads GitHub issues labelled ready-for-agent, assigns up to 4 to parallel Implementers, a Reviewer validates each, and a Merger fast-forwards into main and closes the issue. Sandcastle never creates issues — it only consumes them.

9 Key Architecture Decisions

Decision Choice Rationale
Primary keys Integer (GENERATED ALWAYS) Single instance, no distributed IDs needed. 4B vs 16B (UUID), faster joins.
MBIDs Nullable, non-unique LastFM MBIDs are inconsistent. Store as metadata, not identity.
Album relationship Album on scrobble, not track Same track appears on different albums. Scrobble = "track X from album Y at time T".
Sync trigger CLI + auto-sync on page visit Silent probe on mount, then conditional import. Two modes: silent (≤1 page) and catch-up with spinner.
Query layer Named functions, no repository Explicit db injection. Each function independently evolvable. Split at ~300 lines.
Ingestion separation recordListen() ≠ importScrobbles() recordListen is stable primitive (entity resolution). importScrobbles is orchestration (pagination, sync).
Auth Better Auth — deferred to Phase 6 Don't block first scrobble on auth plumbing.
Playlist export Tidal, not Spotify Spotify deprecated public playlist creation. Tidal = ingestion source + playlist output.
