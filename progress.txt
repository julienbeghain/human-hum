## Iteration 1: packages/db setup (human-hum-1fo)

- Created packages/db with Drizzle ORM + Neon serverless driver
- Star schema: artists, albums, tracks (dimension tables) + scrobbles (fact table)
- Unique constraints: artists(name, mbid), albums(name, artist_id, mbid), tracks(name, artist_id, mbid), scrobbles(track_id, listened_at)
- Source enum: lastfm, spotify, tidal
- Exports: db client, schema, Database type, and createDb factory
- Added DATABASE_URL to turbo.json globalEnv to suppress lint warnings
- Used generatedAlwaysAsIdentity() for auto-incrementing PKs (Postgres identity columns)
- Note: migration not run yet — requires DATABASE_URL env var pointing to Neon

## Iteration 2: LastFM single-page import script (human-hum-4uh)

- Created apps/import with tsx runner for LastFM import
- Fetches one page (50 tracks) from user.getRecentTracks API
- Upserts artists, albums, tracks with select-then-insert-then-refetch pattern for race safety
- Inserts scrobbles with onConflictDoNothing for dedup (unique on track_id + listened_at)
- Skips "now playing" entries (no timestamp)
- Uses `drizzle-orm` eq/and for type-safe WHERE conditions
- Env vars: LASTFM_API_KEY, LASTFM_USER, DATABASE_URL (added to turbo.json globalEnv)
- Run with: `pnpm --filter import run import`

## Iteration 8: Paginated backfill with rate limiting (human-hum-99q)

- Added `backfill` option to ImportOptions — when true, paginates all pages at 200 tracks/page
- Without backfill, single page of 50 (preserves existing behavior)
- Extracted `buildUrl()` and `fetchWithRetry()` helpers to keep the main loop clean
- Exponential backoff on HTTP 429: BASE_DELAY_MS * 2^attempt, up to MAX_RETRIES=5
- 200ms inter-page delay to respect LastFM rate limits
- CLI: `--backfill` flag parsed from process.argv, no arg parser dependency needed
- Added `import:backfill` script alias in apps/import/package.json
- do/while loop with currentPage/totalPages — totalPages comes from first API response's @attr

## Iteration 9: Incremental sync mode (human-hum-wy2)

- Default CLI mode (no flags) = incremental sync: queries MAX(listened_at) - 1 second as `from`
- 1-second overlap window handled by existing unique constraint dedup (onConflictDoNothing)
- Falls back to full backfill recursively when DB is empty (no scrobbles yet)
- Both incremental and backfill modes now paginate at 200/page with inter-page delay
- Added `getLatestScrobbleTimestamp()` query using `max()` aggregate from drizzle-orm
- Recursive call to `importScrobbles` with `backfill: true` keeps the fallback logic in one place
- CLI wrapper simplified: no flag = sync, `--backfill` = full history re-import
- `backfill: backfill || undefined` pattern avoids passing `false` which would skip sync detection

## Iteration 10: Backfill resume + completeness check (human-hum-3lm)

- Resume interrupted backfill: auto-set `to = MIN(listened_at) + 1s` so only older pages are fetched
- `getEarliestScrobbleTimestamp()` and `getScrobbleCount()` added to queries.ts using `min()` and `count()` aggregates
- Completeness check: after backfill, calls `user.getInfo` API to get remote playcount, compares with local COUNT(*)
- `CompletenessResult` type: { localCount, remotePlaycount, coveragePercent }
- Coverage will never be 100% — LastFM counts "now playing" entries and deleted tracks in playcount
- Backfill resume only activates when `to` is not explicitly set — explicit `to` takes precedence
- `let { from, to } = options` — destructuring with `let` allows reassignment in the function body
